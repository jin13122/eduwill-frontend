CURRICULUM

교육과정 커리큘럼

현장에서 인정받는 에듀윌의 실무 중심 커리큘럼!

프롬프트 엔지니어링 기초 & AI 활용 개론
  • AI 프롬프트 기본 개념과 작성법을 익히고 ChatGPT 활용법을 실습.
  • Figma AI를 활용해 UI 디자인을 자동화하고 코드 생성 효율성을 높임.
  • GitHub Copilot으로 코드 자동 완성 및 오류 수정 방법을 학습.
  • AI 기반 개발 환경을 설정하고 자동화된 코드 최적화 실습
웹 퍼블리싱 & 반응형 디자인 개발
  • HTML5, CSS3의 기본 문법과 반응형 웹 디자인 개념을 학습.
  • 웹 표준과 접근성을 고려한 레이아웃 설계 및 크로스 브라우징 테스트 실습.
  • Figma AI로 UI 요소를 빠르게 제작하고, 반응형 웹 스타일 자동 생성.
  • ChatGPT를 활용해 웹 접근성 개선 방법 및 디자인 최적화 적용
UI/UX 디자인 시스템 구축 & 자동화
  • Figma를 활용한 디자인 시스템 구성 및 실무형 UI 설계 익히기.
  • 사용자 경험 최적화를 위한 프로토타이핑과 A/B 테스트 실습.
  • Figma AI를 활용한 디자인 자동 생성 및 UX 개선 기능 적용.
  • ChatGPT로 디자인 피드백을 분석하고 UI 개선 전략을 실습
프론트엔드 프로그래밍 기초 & 코드 자동화
  • JavaScript 기본 문법과 DOM 조작을 이해하고 이벤트 핸들링 실습.
  • 비동기 프로그래밍(Promise, Async/Await) 및 API 연동 기초 익히기.
  • GitHub Copilot을 활용한 코드 자동 완성 및 디버깅 실습.
  • 실무에서 활용하는 JavaScript 패턴과 성능 최적화 기법 적용.
데이터베이스 기초 & 백엔드 연동
  • MySQL 및 NoSQL 개념과 기본적인 데이터베이스 설계 학습.
  • SQL 기본 쿼리(SELECT, INSERT, UPDATE, DELETE) 실습.
  • Node.js 또는 Python을 활용한 데이터베이스 연동 방법 익히기.
  • 프론트엔드에서 REST API를 통해 데이터 저장/조회 구현 실습.
프롬프트 엔지니어링 심화 & AI 기반 코드 최적화
  • ChatGPT를 활용해 코드 리팩토링 및 성능 개선 방법 학습.
  • OpenAI API를 활용해 데이터 처리 및 자동화 기능 적용.
  • GitHub Copilot으로 코드 작성 속도를 높이고 협업 효율성을 강화.
  • AI를 활용한 코드 최적화 및 오류 수정 자동화 실습.
API 연동 및 데이터 처리 자동화
  • REST API 개념을 익히고, Fetch API 및 Axios를 활용한 데이터 요청 실습.
  • JSON 데이터 처리 및 서버와의 비동기 통신 구현 연습.
  • ChatGPT를 활용해 API 문서 자동 생성 및 데이터 분석 실습.
  • OpenAI API를 이용해 실시간 데이터 가공 및 검색 기능 추가.
React.js 프레임워크 활용 및 AI 연동
  • React 기본 문법과 컴포넌트 구조 이해, 상태 관리 기초 학습.
  • React Hooks (useState, useEffect) 및 비동기 데이터 처리 실습.
  • GitHub Copilot 기반 React 컴포넌트 자동 생성 및 최적화.
  • ChatGPT로 코드 오류 수정 및 최적화 가이드를 실습.
프론트엔드 협업 및 배포 자동화
  • Git과 GitHub를 활용한 코드 협업 및 버전 관리 학습.
  • CI/CD 개념을 익히고 Netlify/Vercel을 활용한 자동 배포 실습.
  • GitHub Copilot으로 배포 설정 및 코드 문서화 자동화 실습.
  • 실무에서 활용되는 협업 도구와 배포 전략 적용
웹 성능 최적화 기술

  • SEO(검색 엔진 최적화) 및 메타 태그 활용
  • Lighthouse를 활용한 성능 분석 및 개선 사례

  • 기업별 요구하는 AI 기술 역량을 바탕으로 실무 연계 방안 도출.

K-디지털 트레이닝 (디지털 신기술 핵심 실무인재 양성훈련)이란? 4차 산업혁명 및 코로나19로 인해 사회, 경제 전 분야의 디지털화가 가속화되며 첨단산업 디지털 분야 실무역량을 갖춘 인력의 수요가 증대되었고, 인공지능, 빅데이터 등 첨단산업 디지털 분야의 핵심 실무인재 양성하기 위한 직업 훈련의 필요성 대두됨. 특히, 구직 청년과 실직, 경력단절 등 일자리 어려움에 처한 국민에게 기업현장 맞춤형 직업훈련을 제공하여 노동시장 진입을 촉진하기 위해 K-디지털 트레이닝 사업 시행하게 되었으며, 문제해결능력 향상을 위한 새롭고 다양한 훈련방식을 활용한 훈련과정 및 운영역량이 있는 공급자(우수대학, 민간혁신 교육기관, 기업 등)를 선정하여 첨단산업 디지털 핵심 실무인재 양성을 지원하는 제도
